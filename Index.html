Как установить

Нужен Minecraft Java 1.21.11. Всё остальное бесплатно.

  1. 1

    Поставь Fabric Loader

    Скачай установщик с fabricmc.net и выбери версию 1.21.11.

  2. 2

    Добавь Fabric API

    Скачай Fabric API для 1.21.11 и положи файл в папку .minecraft/mods.

  3. 3

    Положи клиент

    Скачай OlawClient-3.5.jar и положи его туда же, в mods.

  4. 4

    Запусти игру

    Выбери профиль Fabric в лаунчере. Меню открывается на Right Shift.

Вопросы и ответы

Не нашёл ответ? Спроси в Discord или Telegram.

Какая версия Minecraft нужна?

Minecraft Java 1.21.11 с Fabric Loader и Fabric API. На других версиях клиент не запустится.

Как открыть меню?

Нажми Right Shift. Поиск модулей открывается на Ctrl+F, настройки модуля открывает правая кнопка мыши.

Это бесплатно?

Да, клиент бесплатный. Поддержать автора можно по желанию.

Меня не забанят на сервере?

Attack Aura, Fly, X-Ray и похожие модули запрещены правилами многих серверов. Перед игрой проверь правила сервера.

Куда писать об ошибках?

В Discord или Telegram. Напиши версию клиента и что ты делал, когда появилась ошибка.

Чит-клиент для Minecraft 1.21.11

Olaw Client — бесплатный чит для Minecraft Java 1.21.11 на Fabric. В нём 83 модуля: KillAura (Attack Aura), Aim Assist, Trigger Bot, Crystal Aura, ESP, X-Ray, Tracers, Fly, Speed, Scaffold, Auto Totem, No Fall и другие.

Все функции открываются в одном меню «Орбита» по Right Shift. Есть свой HUD, Free Look, Zoom, Item Physics и косметика: крылья, плащи, шляпы и питомцы. Клиент ставится как обычный мод: положи файл в папку mods рядом с Fabric API.
